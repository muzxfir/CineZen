# CineZen Movie Discovery Website

A mobile-first static movie discovery website linked to:

- Telegram Bot: https://t.me/SADIEMOLBOT
- Telegram Channel: https://t.me/CineZenHQ

## Files
- index.html
- style.css
- script.js

## How to use
1. Upload these files to GitHub Pages, Netlify, Vercel, or any static hosting.
2. Replace the sample movie entries inside `script.js` with your own catalog.
3. Only publish or link to content you are authorized to distribute.

## Customize
Edit `script.js`:
- movie title
- year
- language
- genre
- quality
- poster
- description
- trailer

The “Get on Telegram” button opens SADIEMOLBOT with a start parameter based on the movie title.
